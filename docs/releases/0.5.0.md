## Community contributions

Thank you **@fullstackfool** for the improvements in [their fork](https://github.com/fullstackfool/homeassistant-pawfit), now merged with the original commit history:

- Rate-limited location and activity polling, a shared HTTP session and API request counting.
- A 15-minute last-known-data grace period during transient outages.
- Locate, stale-position metadata and initial polling/Locate regression tests.

## Reliability and compatibility fixes

- Rebuild authenticated URLs and signatures after session renewal; limit token retries and serialize login refreshes.
- Add Home Assistant reauthentication and distinguish rejected credentials, connection failures and invalid API responses.
- Require a new position for Locate. Report failed start/stop commands, bound cleanup retries and clean up owned Find modes on unload. Respect manually enabled Find modes.
- Preserve missing trackers briefly during partial responses, then expire each tracker independently.
- Preserve valid same-day activity totals on failures instead of writing false zeroes.
- Validate coordinates, timestamps, battery encodings and mode timers. Coordinates at zero are valid.
- Remove private API payloads and authenticated URLs from client logging; bound network timeouts and activity decompression.
- Preserve existing entity unique IDs and correct documentation links back to this repository.

## Testing and installation

- Expand to 120 automated tests using synthetic API responses and Home Assistant's test harness.
- CI runs Home Assistant 2026.9.4 and 2026.10.4 on Python 3.14 and enforces at least 95% combined statement/branch coverage.
- Require Home Assistant 2026.9 or newer. Keep the `pawfit.zip` HACS release layout; release publication now requires passing tests and a matching tag/manifest version, and includes these credited notes.

Use a separate shared Pawfit account, as described in the README. Cached map markers are last-known positions. Tests cover software behaviour; the changes have not yet been validated against physical trackers in this review.

Manual installation: extract `pawfit.zip` into `custom_components/pawfit/`, then restart Home Assistant. HACS users can update normally when this release is published.
